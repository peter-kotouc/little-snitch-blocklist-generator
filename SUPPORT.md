# Support

Thanks for using the Little Snitch Blocklist Generator! Here's where to go
depending on what you need.

## 📖 Documentation

- **Usage, presets, and deploying your own instance:** see the
  [README](README.md)
- **Adding a blocklist or contributing code:** see
  [CONTRIBUTING.md](CONTRIBUTING.md)

## 🚫 A domain is wrongly blocked (false positive)

This project only aggregates and merges upstream blocklists — it does not
curate individual domains. Please contact the maintainers of the respective
**upstream blocklist** directly; the **Included Blocklists** table in the
[README](README.md) links every upstream source.

## 🐛 Something is broken

If the API, the fetch pipeline, or the generated rulesets misbehave, please
[open a bug report](https://github.com/peter-kotouc/little-snitch-blocklist-generator/issues/new/choose)
and include the request URL you tried, what you expected, and what happened.

## 🛡️ You want a new blocklist included

Open a
[blocklist request](https://github.com/peter-kotouc/little-snitch-blocklist-generator/issues/new/choose)
with the list's URL, description, and license — or submit a Pull Request
yourself by following [CONTRIBUTING.md](CONTRIBUTING.md).

## 🔒 Security issues

Please do **not** open a public issue. Follow the instructions in
[SECURITY.md](SECURITY.md) instead.

## ⏱️ Response times

This is a personal project maintained on a best-effort basis — there is no
guaranteed response time, but issues are usually looked at within a week.
